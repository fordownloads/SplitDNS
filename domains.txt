# Split DNS: hosts-like syntax, but the first column is a DNS server instead of an IP.
#
#   <dns>[,<dns>...] <name> [<name> ...]     # comment
#
#   dns       - IP, or on Android also a dnsproxy URL: https://... tls://... quic://...
#               (Windows/NRPT takes plain IPs only, URLs are skipped there)
#   name      - exactly this name (Android: this name AND its subdomains)
#   .name     - only subdomains of name (*.name), not name itself
#   *         - default server for everything else
#               (Windows: NRPT rule "."; Android: if omitted, the DNS of the active VPN/network is used)
#
# A name listed on several lines belongs to the first one: upper groups win.
#
# WebUI metadata (plain comments for everything else):
#   # @group on|off <name>   starts a group; lines of a disabled group are written as "#@ ..."
#   # @global                default servers ("*" line) follow
